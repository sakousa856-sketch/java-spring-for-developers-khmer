## ☕ ១. ប្រវត្តិនៃការកកើត Java (The Origin)

**Java** គឺជាភាសាសរសេរកម្មវិធីដ៏មានឥទ្ធិពលមួយ ដែលត្រូវបានបង្កើតឡើងដោយលោក **James Gosling** និងក្រុមការងារនៅក្នុងក្រុមហ៊ុន **Sun Microsystems** ក្រោមគម្រោងស្រាវជ្រាវសម្ងាត់មួយឈ្មោះថា **Green Project** នៅឆ្នាំ **១៩៩១**។

### 🌳 ការវិវត្តនៃឈ្មោះ (Oak ទៅជា Java)
* គម្រោងនេះបានប្រើប្រាស់ភាសាមួយដែលមានមូលដ្ឋានឈរលើភាសា **C** និង **C++**។
* 🌿 **ឈ្មោះដំបូង (Oak):** ដំបូងឡើយ ភាសានេះត្រូវបានដាក់ឈ្មោះថា **Oak** ដោយសារតែលោក James Gosling បានឃើញដើម Oak ដ៏ធំមួយតាមរយៈបង្អួចការិយាល័យរបស់គាត់នៅក្នុងក្រុមហ៊ុន Sun Microsystems។
* ☕ **ប្តូរមកជា Java:** ក្រោយមក ឈ្មោះនេះត្រូវបានស្នើឱ្យប្តូរទៅជា **Java** តាមការបំផុសគំនិតរបស់មិត្តរួមការងារបន្ទាប់ពីពួកគេបានចេញពីហាងកាហ្វេ។ ឈ្មោះ **Java** (ដែលជាឈ្មោះកោះកាហ្វេដ៏ល្បីល្បាញ) ក៏ត្រូវបានជ្រើសរើស និងប្រើប្រាស់ជាផ្លូវការរហូតមកដល់សព្វថ្ងៃនេះ។

## 🌐 ២. គម្រោង Green Project និងការរស់ឡើងវិញដោយសារ Web

> [!NOTE]
> ### ⚠️ ឧបសគ្គដំបូង (Initial Struggles):
> ការងារដំបូងរបស់ **Green Project** គឺដើម្បីបង្កើត Software សម្រាប់ឧបករណ៍អេឡិចត្រូនិចឆ្លាតវៃ (Smart Appliances & Set-Top Boxes) ប៉ុន្តែទីផ្សារនៅពេលនោះមិនទាន់ត្រៀមខ្លួនរួចរាល់ឡើយ ជាហេតុធ្វើឱ្យកិច្ចសន្យាសំខាន់មួយរបស់ក្រុមហ៊ុន Sun ត្រូវបានធ្លាក់ទៅលើដៃគូប្រកួតប្រជែង ហើយគម្រោងនេះស្ទើរតែត្រូវដួលរលំបិទបញ្ចប់ទាំងស្រុង។

### 🚀 របកគំហើញនៃ World Wide Web (១៩៩៣)
* សំណាងល្អ នៅឆ្នាំ **១៩៩៣** បណ្តាញ **World Wide Web (WWW)** បានចាប់ផ្តើមលេចធ្លោឡើងយ៉ាងខ្លាំងក្លាលើពិភពលោក។
* ក្រុមការងារនៅក្រុមហ៊ុន Sun បានមើលឃើញយ៉ាងច្បាស់ពី **អានុភាពនៃការប្រើ Java ដើម្បីបង្កើត Web Applications អន្តរកម្ម (Interactive Web Pages & Applets)**។
* ឱកាសនៃយុគសម័យ Web នេះហើយដែលបានជួយស្រោចស្រង់ និងធ្វើឱ្យគម្រោង Java រស់រវើកឡើងវិញ ក្លាយជាភាសា Programming លេខមួយសម្រាប់ប្រព័ន្ធ Enterprise ពិភពលោក!

## 💡 សេចក្តីសង្ខេបសំខាន់ (Key Takeaways)

> [!TIP]
> 1. **ស្ថាបនិក:** លោក **James Gosling** (Father of Java) នៅក្រុមហ៊ុន Sun Microsystems (1991)។
> 2. **ឈ្មោះដើម:** ឈ្មោះដើមគឺ **Oak** មុនពេលប្តូរមកជា **Java**។
> 3. **កត្តាជោគជ័យ:** ការមកដល់នៃ **World Wide Web (1993)** បានធ្វើឱ្យ Java ក្លាយជាបច្ចេកវិទ្យាដ៏ពេញនិយមបំផុតសម្រាប់គេហទំព័រ និងប្រព័ន្ធ Server។
