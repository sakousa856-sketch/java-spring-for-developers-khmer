# CLAUDE.md

This file provides guidance when working with code in this repository.

## Project Overview

This repository holds the comprehensive interview preparation handbook and career roadmap: **"Java & Spring Developer Career & Interview Handbook" (ខេមរភាសា)**.
It covers everything a modern backend engineer needs to master to pass technical interviews and excel in enterprise software roles (from Junior to Senior/Lead Backend Developer).

## Core Pillars (12 Modules)

1. **`01-core-java-and-jvm-internals/`** — JVM, Memory Model, Garbage Collection, Java 8-21 Features
2. **`02-oop-solid-and-design-patterns/`** — OOP, SOLID Principles, GoF Design Patterns
3. **`03-concurrency-multithreading-virtual-threads/`** — Threading, Locks, Concurrency, Virtual Threads (Java 21)
4. **`04-spring-framework-core-architecture/`** — IoC, DI, Bean Lifecycle, AOP, Proxies
5. **`05-spring-boot-deep-dive-and-production/`** — Auto-configuration, Starters, Actuator, Profiles
6. **`06-sql-database-indexing-spring-data-jpa/`** — SQL, Indexing, Transactions, Hibernate, N+1 Problem, Locking
7. **`07-microservices-and-system-design-patterns/`** — Architecture, Gateway, Eureka, Saga, CQRS, Circuit Breakers
8. **`08-event-driven-architecture-and-kafka/`** — Kafka Architecture, Partitions, Consumer Groups, DLQ
9. **`09-spring-security-jwt-and-oauth2/`** — SecurityFilterChain, JWT, OAuth2/OIDC, RBAC
10. **`10-automated-testing-junit-mockito-testcontainers/`** — Unit, Slice, Integration Testing, Testcontainers
11. **`11-devops-docker-kubernetes-observability/`** — Docker, Kubernetes, CI/CD, Distributed Tracing
12. **`12-system-design-scenarios-and-live-coding/`** — System Design Scenarios, Live Coding Patterns, Behavioral STAR

## Content Conventions

- **Bilingual Mirroring:** Every module folder MUST contain both `README.kh.md` (Khmer) and `README.md` (English) mirroring each other 1:1.
- **Deep Technical Accuracy:** Explain not just the "what", but the internal "how" and "why" that interviewers test for.
- **Interviewer Tips Box:** Include `> **💡 Interviewer's Trap / អ្វីដែលអ្នកសម្ភាសន៍ចង់ឮ:**` callouts.
- **Modern Standards:** Target modern Java (17/21 LTS), Spring Boot 3.x, and cloud-native practices.
