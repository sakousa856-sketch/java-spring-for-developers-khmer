# មេរៀនទី ១៖ សេចក្តីផ្តើមអំពី Java OOP (Java OOP Introduction)

### 🖥️ ស្លាយទី 01 ｜ Slide 01

> ## 📌 Advance Java 1 Tutorial
> 
> ---
>
> **Java** គឺជាភាសាកម្រិតខ្ពស់ (High-level programming language) ដែលត្រូវបានបង្កើតឡើងដំបូងដោយក្រុមហ៊ុន **Sun Microsystems** និងបានចេញផ្សាយជាផ្លូវការនៅឆ្នាំ **1995**។ Java អាចដំណើរការបាននៅលើប្រព័ន្ធប្រតិបត្តិការ (Platforms) ជាច្រើនដូចជា Windows, Mac OS និងប្រភេទផ្សេងៗនៃ UNIX។

---

### 🖥️ ស្លាយទី 02 ｜ Slide 02

> ## 📌 Java OOP Concept
> 
> ---
>
> **OOP (Object-Oriented Programming)** គឺជា Structure មួយដែលត្រូវបានគេប្រើប្រាស់សំរាប់បង្កើតនូវ Software ក្នុងទម្រង់ជា Unit ហើយត្រូវបានគេគ្រប់គ្នាស្គាល់ថាជា **Object**។ 
>
> ### សារប្រយោជន៍នៃការប្រើប្រាស់ OOP មានដូចជា:
> - មានល្បឿនលឿន និងងាយស្រួលក្នុងការ Execute កូដ។
> - ផ្តល់នូវ Structure មួយដែលមើលទៅងាយយល់នៅក្នុង Program។
> - ធ្វើឲ្យកូដសរសេរទៅគ្មានភាពច្រំដែល, ងាយស្រួលក្នុងការត្រួតពិនិត្យកូដ, និងងាយស្វែងរក Error នៅក្នុង Program។
> - ចំណេញពេលវេលាក្នុងការអភិវឌ្ឍ។
