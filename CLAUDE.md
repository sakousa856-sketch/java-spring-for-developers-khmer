# Java & Spring Framework Master Engineering Curriculum

A comprehensive, industry-grade software engineering curriculum covering Basic Java, Advance Java OOP, Spring Framework Core Architecture, Spring Boot Enterprise Microservices, and Technical Interview Preparation in Khmer (ខេមរភាសា).

## Repository Information
- **Repository**: `https://github.com/sakousa856-sketch/java-spring-for-developers-khmer`
- **Scope**: 5 Master Tracks (148 Lessons + 234 Presentation Slides + Master Roadmap)
- **Author**: Sak Ousa (sakousa856-sketch)
- **Language**: Khmer (ខេមរភាសា) / English

## Architecture & Tracks
1. `01-basic-java/`: 18 Lessons (87 Slides) covering History, Versions, Syntax, Types, I/O, Operators, Control Flow, Loops, Arrays.
2. `02-advance-java/`: 18 Lessons (86 Slides) covering Object-Oriented Programming (OOP), Classes, Inheritance, Polymorphism, Encapsulation, Abstraction, Interfaces.
3. `03-spring-framework/`: 24 Lessons (61 Slides) covering IoC Container, Dependency Injection, Bean Lifecycles, Scopes, AOP.
4. `04-spring-boot/`: 10 Modules (78 Lessons + 5 Projects) covering REST APIs, Spring Data JPA, Security & JWT, Microservices, Caching.
5. `05-interview-handbook/`: 12 Master Pillars covering Core Java Internals, Spring Architecture, System Design, Live Coding Scenarios.
6. `ROADMAP.md`: The 6-Phase Master Full Stack Career Roadmap.
